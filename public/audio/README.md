Drop your own MP3 files here (e.g. `01-yashomati-maiya.mp3`), then set the
matching song's `"mp3"` field in `src/data/songs.json` to `/audio/your-file.mp3`.

Only add MP3s you own or have the rights to use — this repo does not (and
should not) ship copyrighted commercial audio.

Songs left with `"mp3": ""` automatically fall back to YouTube playback.
